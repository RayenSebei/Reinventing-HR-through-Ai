# Rebuttal — Defense

**1. Schedule vs scope: survives as a risk, not a verdict.** The team chose "ONE polished end-to-end recruitment workflow" and lists what it won't build. Hashing, a hash chain and single-use approvals are small deterministic code. The open team size is a real gap, and the fix is cutting forensic checks down to the demoed fixtures.

**2. Demo on unproven work: survives in part.** It's true that no scenario has run against Vouch. But the gateway-rejection beat doesn't need SENTINEL, the live slot uses only 5 of the 24 scenarios, and the team refuses to claim "production-secure." The fix is to schedule integration before hours 13 to 14.5.

**3. Undefined requirements: mostly fails.** The organizers left "real volumes" undefined, so the team can set its own target. The record answers the approval scope: "Telemetry/security logs recorded automatically; consequential record changes and external communications need approval." Only the quality of French, Arabic and English handling stays open.

**4. Circular security: partly survives.** Testing hidden content only on the team's own fixtures is a real limit, though fictional data is the event's rule. Forged-approval, tampering and cross-case checks still pass or fail objectively, whoever wrote them.

**5. No startup foundation: fails as grounds to stop.** No team validates a market in 17 hours, and the spec only asks teams to act as startups. Incumbents shipping HR agents supports the case for independent testing.

**Decisive point:** Point 2. Can SENTINEL run live against a real Vouch API before the pitch?
